# 🧮 CODSOFT Calculator

A modern, stylish, and functional **React-based calculator app** built as part of the CODSOFT Internship Program.  
This calculator features a clean UI, smooth gradients, and responsive design — making basic arithmetic operations simple and elegant.

---

## 🚀 Features

- Perform basic math operations: `+`, `-`, `*`, `/`, `%`
- Clear (`AC`) and Backspace (`<-`) functionality
- Responsive design with modern Tailwind CSS styling
- Aesthetic gradient background with glass-like calculator display
- Built using **React + Tailwind CSS**

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Language:** JavaScript (ES6+)
- **Icons & Fonts:** Google Fonts / Custom CSS effects

## ⚙️ Installation & Setup

Follow these steps to run this project locally:

```bash
# 1️⃣ Clone the repository
git clone https://github.com/Aman0835/CODSOFT-calulator.git

# 2️⃣ Move into the project directory
cd CODSOFT-calulator

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server
npm run dev
```
